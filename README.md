# Youth Mental Wellness - Demo Application

A confidential AI-powered mental wellness platform designed specifically for youth in India.

## 🌟 Features

- **Confidential AI Chatbot**: Empathetic AI responses for emotional support
- **Mood Tracking**: Daily mood check-ins with journaling capabilities  
- **Resource Hub**: Curated mental wellness resources and guided exercises
- **Anonymous Community**: Safe peer support forum
- **Professional Help Directory**: Local mental health resources and emergency contacts
- **Cultural Awareness**: Content tailored for Indian youth

## 🚀 Quick Start

### Prerequisites

- Node.js 16+ 
- npm or yarn

### Backend Setup

1. Navigate to backend directory:
```bash
cd backend
```

2. Install dependencies:
```bash
npm install
```

3. Start the server:
```bash
npm start
```

The backend will run on http://localhost:5000

### Frontend Setup

1. Navigate to frontend directory:
```bash
cd frontend
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The frontend will run on http://localhost:3000

## 🔧 Development

### Running Both Services

From the root directory, you can run both frontend and backend:

**Terminal 1 (Backend):**
```bash
cd backend && npm start
```

**Terminal 2 (Frontend):**
```bash
cd frontend && npm start
```

## 📱 Demo Flow

1. **Landing Page** - Introduction and privacy assurance
2. **Onboarding** - Anonymous user preferences setup
3. **AI Chatbot** - Main interaction point for emotional support
4. **Mood Tracker** - Daily emotional check-ins and journaling
5. **Resource Hub** - Educational content and wellness exercises
6. **Community Forum** - Anonymous peer support
7. **Professional Help** - Crisis resources and referral information
